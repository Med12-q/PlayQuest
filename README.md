  ## ✦ À propos

  **PlayQuest** est un réseau social nouvelle génération à l'esthétique **cyberpunk** — rouge sang, noir profond, néon bleu. Inspiré de SnapQuest mais bien au-delà : un vrai réseau social avec feed, stories, reels, musique, IA, messages et bien plus.

  ---

  ## 🚀 Fonctionnalités

  | Section | Description |
  |---------|-------------|
  | 🏠 **Landing** | Aurora animée, stats compteurs, témoignages, CTA premium |
  | 📊 **Dashboard** | Analytics personnalisés, graphiques SVG, LYRA IA tips |
  | 📰 **Feed** | Posts avec vraies images Unsplash + vidéos YouTube |
  | 📱 **Stories** | Stories 24h avec gradients colorés |
  | 🎬 **Reels** | TikTok-style vertical video player |
  | 🎵 **Music** | Player Spotify-like avec 8 tracks persistants |
  | 🔍 **Explore** | Hashtags trending, découverte d'utilisateurs |
  | 💬 **Messages** | Messagerie privée temps réel (BroadcastChannel) |
  | 🔔 **Notifs** | Centre de notifications avec type icons |
  | 👤 **Profil** | Grille posts, follow/unfollow, stats live |
  | ⚙️ **Settings** | Édition profil, préférences, déconnexion |
  | 🤖 **LYRA IA** | Assistant vocal IA en français (Web Speech API) |

    Corps    →  Inter

  ✨ Effets:
    Glassmorphism + backdrop-filter
    Neon glow (box-shadow multicouche)
    Aurora animated blobs
